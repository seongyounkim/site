# 새 홈페이지 적용 방법

이 버전은 왼쪽에 사진·이름·연락처·메뉴가 있고 오른쪽에 연구 내용을 배치한 전통적인 academic 홈페이지 형식입니다. JavaScript나 외부 폰트를 사용하지 않습니다.

## GitHub에 반영

저장소 최상단에서 다음 항목을 새 파일로 덮어쓰세요.

- `index.html`
- `styles.css`
- `assets` 폴더
- `cv.pdf`
- `.nojekyll`

GitHub 웹에서 `Add file` → `Upload files`를 누른 뒤, 압축을 푼 폴더 **안의 파일들**을 업로드하면 됩니다. `source/cv.tex`는 홈페이지 작동에는 필요 없으며, CV를 수정할 때 사용할 LaTeX 원본입니다.

## 사진 교체

1. 사용할 사진을 세로형으로 준비합니다. 정사각형 사진도 자동으로 잘립니다.
2. 파일 이름을 정확히 `profile.jpg`로 바꿉니다.
3. GitHub 저장소의 `assets` 폴더에 들어갑니다.
4. 기존 `profile.jpg`를 새 사진으로 덮어씁니다.

사진은 화면에서 4:5 비율로 잘리며 얼굴이 위쪽에 오도록 설정되어 있습니다. 얼굴 위치가 맞지 않으면 `styles.css`의 다음 값을 조정하면 됩니다.

```css
object-position: center 24%;
```

예를 들어 얼굴을 조금 아래로 보이게 하려면 `24%`를 `18%` 정도로 낮추고, 조금 위로 보이게 하려면 값을 높입니다.

## 홈페이지 내용 수정

모든 홈페이지 문구는 `index.html`에 있습니다. 텍스트를 수정한 뒤 커밋하면 됩니다.

## CV 수정

1. `source/cv.tex`를 Overleaf에 업로드합니다.
2. 내용을 수정하고 PDF를 컴파일합니다.
3. 결과 파일 이름을 `cv.pdf`로 바꿉니다.
4. GitHub 저장소 최상단의 기존 `cv.pdf`를 덮어씁니다.

## 배포 확인

커밋 후 `Actions`에서 Pages 배포가 초록색 체크로 끝난 것을 확인한 뒤, 사이트에서 `Command + Shift + R`로 새로고침하세요.
